# Support

This file is the organisation-wide fallback. A repository with its own
`SUPPORT.md` overrides it.

| You want to | Go here |
| --- | --- |
| Report a bug in the website | Open an issue on [ludwise-web](https://github.com/ludwise/ludwise-web/issues) |
| Report a vulnerability | Email git@danielkindl.dev — see `SECURITY.md`, not an issue |
| Suggest a feature | Open an issue and say what you are trying to do |
| Ask how something works | Open an issue |

A bug report is easier to act on with the page URL, what you expected, what
happened instead, and the `x-request-id` header from the response if you can get
it.

There is no support inbox and no service level. One maintainer, best effort.
