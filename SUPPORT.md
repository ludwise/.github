# Support

This file is the organization-wide fallback. A repository can have its own
`SUPPORT.md`. If it does, use the repository file.

| Task | Contact |
| --- | --- |
| Report a bug in the website | Open an issue on [ludwise-web](https://github.com/ludwise/ludwise-web/issues) |
| Report a vulnerability | Email security@ludwise.com. Do not open an issue. |
| Ask for help | Email support@ludwise.com |
| Suggest a feature | Open an issue and explain what you want to do |
| Ask how something works | Open an issue |

For a bug report, include the page URL, the expected result, and the actual
result. If possible, also include the `x-request-id` response header.

We do not guarantee a response time or service level.
