# LUDWISE

LUDWISE is building a simple, trusted way to discover and compare PC games, storefront offers, prices, price history, and upcoming releases.

Our focus is straightforward: useful game discovery and comparison without unnecessary complexity.

## Repositories

- [ludwise-web](https://github.com/ludwise/ludwise-web) — public web client
- Backend and infrastructure repositories are kept private.
